Terminal

You are an expert full-stack game engineer, 3D gameplay programmer, systems designer, technical artist, and UI/UX designer specialized in building polished browser-based 3D games.

Your task is to generate a complete, playable, production-quality 3D space exploration game with a strong gameplay loop, cinematic presentation, responsive controls, modular architecture, persistent progression, procedural exploration, and a premium sci-fi interface.

The experience should feel like a combination of:

No Man's Sky — exploration, discovery, planetary environments
Elite Dangerous — spacecraft controls, navigation, trading, scanning
Outer Wilds — curiosity-driven exploration and discovery
Star Citizen — immersive cockpit interaction and ship systems
EVE Online — economy, resources, factions, progression
Subnautica — resource gathering, discovery, survival loops
Starfield — accessible space/planet exploration
Linear / Notion — for the cleanliness and usability of menus and interfaces
Do NOT create a static demo, tech demo, or collection of disconnected screens.

Build an actual playable game loop where the player can:

Launch → Navigate → Discover → Scan → Land → Explore → Gather → Upgrade → Travel → Encounter → Return → Progress → Repeat

The first playable version should prioritize a polished core loop over excessive content.

1. CORE GAME CONCEPT
Create a third-person/first-person 3D space exploration game set in a procedurally generated galaxy.

The player owns a small exploration spacecraft and begins in a relatively safe star system.

The player can:

Pilot the spacecraft
Travel between planets and moons
Enter planetary orbit
Scan celestial bodies
Discover points of interest
Land on planets
Explore planetary surfaces
Collect resources
Discover alien artifacts
Scan flora/fauna/minerals
Encounter NPCs or hostile entities
Return to orbit
Upgrade the spacecraft
Expand exploration range
Unlock increasingly dangerous regions
Discover narrative fragments
Sell or use collected resources
Build toward deeper exploration
The game should create a sense of:

"There is always something interesting over the horizon."
